# 🚗 cpa-plugin-carpool (CPA 拼车管家)

**为 CLIProxyAPI (CPA) 打造的轻量级多租户拼车合租微服务插件**

*独享席位绑定 · 买家自助 Portal · 额度双刷新倒计时 · 撞限一键满血重置 · 零信任隐私隔离*

[技术设计规格书 (SPEC.md)](./SPEC.md) · [协议条款 (LICENSE)](./LICENSE)

## 💡 为什么需要 cpa-plugin-carpool？

在把 ChatGPT Team、Claude Team 或个人高倍席位出租拼车时，车主和买家长期面临两难困境：

* ❌ **Sub2API / NewAPI 太重**：需要额外搭建 MySQL、Redis 和独立 Docker 容器堆栈，常驻内存数百 MB，运维极度繁琐；
* ❌ **纯 CPA / key-router 太简陋**：
  * 没有面向买家的查额度界面；
  * 同一邮箱存在多个账号（如 Team 席位 + 个人 Pro 5x）时，现有插件存在严重的同名规则混淆与越权漏洞；
  * 买家一写错脚本撞限 429，就只能半夜找车主看后台、人工查额度、手动点重置，**车主沦为 24 小时随叫随到的客服**。

**cpa-plugin-carpool** 专为个人车主与轻量合租而生：直接内嵌在 CPA 内部，零数据库、零多余进程。车主一键生成专属 Key 并发货，买家自主打开链接查额度、看倒计时，撞限时 **2 秒内自主核销官方重置卡瞬间满血复活**！

## ✨ 核心亮点

### 1. ⏱️ 额度双刷新动态倒计时
* **5小时短窗刷新倒计时**：实时动态递减计算（例如：`⏱️ 5小时额度刷新倒计时：剩余 1 小时 23 分`）；
* **周限额度刷新时间**：对齐买家本地星期与时刻（例如：`📅 周限额度刷新时间：周日 18:00 (剩余 3 天)`）。

### 2. ⚡ 撞限 2 秒自主核销重置卡
* 实时展示该席位拥有的官方重置卡列表（发放时间、失效时间、历史使用时间）；
* 买家赶项目写代码撞限（429 Too Many Requests）时，在页面上一键核销，瞬间调用上游回血并同步解除网关本地冷却，**全程无需车主干预**。

### 3. 🛡️ 零信任安全与物理隔离 (Zero-Trust PII Masking)
* **字段白名单过滤**：严格剔除上游账号的真实邮箱、`account_id`、`user_id`、Token，买家抓包也绝对看不到车主的任何隐私信息；
* **物理 1 对 1 绑定**：基于精确 Auth ID 调度，彻底修复 `key-router` 对同邮箱多账号的混淆 Bug；
* **防越权查询**：买家 A 凭自己的 Key 只能查自己的席位，未配置的 Key 无论是否有效均直接拒绝。

## 🗺️ 开发路线 (Roadmap)

- [x] **v0.1.0 (Prototype)**: 独立微服务验证跑通、实时倒计时算法、一键核销与零信任脱敏。
- [ ] **v0.2.0 (Native ABI)**: 封装为 Go 原生动态库 `.so`，实现 `pluginapi.Scheduler` 与 `ResourceRoutes`，摆脱 Python 守护进程。
- [ ] **v0.3.0 (Security & Limits)**: 单 Key RPM/并发限频、到期自动失效（`expire_at`）、重置卡单周使用配额。
- [ ] **v0.4.0 (Plugin Store)**: 提交至官方 CLIProxyAPI Plugins Store，支持管理面板一键无缝安装。
