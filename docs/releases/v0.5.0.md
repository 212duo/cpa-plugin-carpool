首次提供正式安装包，包含车主管理、买家自助 Portal 和独立请求监控。

## 更新内容

- **请求监控**：查看当前 Key 的调用次数、成功率、Token、模型汇总和近期请求，支持时间与成功 / 失败筛选。
- **数据隔离**：同席位、同上游账号的不同 Key 分别统计；不展示上游账号、凭据、请求内容或原始错误。撤销或到期的 Key 无法通过缓存继续访问。
- **宽屏页面**：Portal 与管理页加宽，席位、额度和用量并排展示；客户端配置默认折叠，手机自动适配。
- **车主管理**：增删改席位、生成 Key、绑定账号、设置租期与限额，查看用量并复制买家链接。
- **历史用量修复**：数据库不可用时明确提示，不再显示成 0；修正少量 Token 和标准化输入 / 缓存读取统计。
- **减少查询开销**：近期记录缓存 10 秒、汇总缓存 30 秒，合并重复请求并限制查询并发；页面显示各自更新时间，切到后台暂停刷新。

## 配置与兼容性

- 适用于 **CLIProxyAPI v8.0.30 及以上**，提供 Linux x86-64（amd64）和 ARM64 安装包。
- 请求监控与历史用量依赖 **CPA Manager Plus 的 `usage.sqlite`**。需把完整数据目录（包括 WAL / SHM）只读挂载给 CPA，并配置 `db-path`；只安装插件不会自动采集历史记录。
- 大数据库建议在 Manager 的数据库写入端执行包内的 `scripts/usage-monitor-index.sql`，添加查询索引。脚本可重复执行，插件保持只读数据库。
- 手动安装时，将 `cpa-carpool.so` 放入 CPA 插件目录并重启；已有席位与 Key 配置可保留。详细步骤见 [README](https://github.com/212duo/cpa-plugin-carpool/blob/v0.5.0/README.md)。
